# AGENTS.md

Instructions for AI coding assistants working in this repository. Humans should start with
[README.md](README.md) and [CONTRIBUTING.md](CONTRIBUTING.md), which describe the same workflow.

## What this is

40K Reminders turns a Warhammer 40,000 eleventh edition army (faction, detachment, enhancements,
units) into reminders grouped by the moment each rule comes up. It is a fork of Davis E. Ford's
[AoS Reminders](https://github.com/daviseford/aos-reminders), retooled for 40K and hosted on GitHub
Pages.

## Non-negotiable constraints

- Never push or merge `master` without the owner's explicit say-so. A push to `master` deploys the
  live site through `.github/workflows/pages.yml`. Work on a branch.
- Do not offer anything AoS Reminders charges for: no accounts, saved armies, share links, or dark
  theme. Account routes forward to aosreminders.com.
- Keep the credit to Davis E. Ford and AoS Reminders in the masthead, footer, FAQ, README, and
  LICENSE.
- Keep the "Powered by Wahapedia" attribution in the footer and README.
- Never hand-edit `src/wh40k11e/generated/runtime.json`. It is generated by
  `yarn data:wh40k11e:generate:write` from reviewed inputs.
- Never commit raw source files (PDFs, CSV exports, BSData JSON). They live in the ignored `.cache/`.
- Treat display names as text, never as identity. Rules, datasheets, and detachments are keyed by
  stable source-record IDs.
- The domain, selection, reminder, state, view, and generated layers under `src/wh40k11e/` must not
  import the Node-only data pipeline. `src/tests/wh40k11e/architectureBoundaries.test.ts` enforces it.

## Source precedence

1. Games Workshop publications are the authority.
2. Wahapedia's eleventh edition exports and BSData catalogues are co-equal secondary sources.
3. Disagreements are recorded and resolved in favour of the newest official document, or left for
   review. Every hand decision lives in `data/wh40k11e/reviews/*.json` with a reason, and quotes the
   official page when one is pinned.

## Layout

- `src/wh40k11e/data/` - acquisition, Wahapedia decoding and linking, source review, rule building
- `src/wh40k11e/normalize/` - WHEN-clause and ability timing parsers
- `src/wh40k11e/domain/` - rule, timing, catalog, and runtime types plus catalog validation
- `src/wh40k11e/select/`, `reminders/`, `view/`, `state/`, `runtime/` - army selection, reminder
  projection, view models, the army document, and browser storage
- `src/wh40k11e/generated/` - the checked-in runtime the app loads
- `src/aos4/` - acquisition, normalization, and domain helpers inherited from AoS Reminders and
  still used by the 40K pipeline
- `src/components/` - the React interface; `routes/Wh40kHome.tsx` is the main screen
- `data/wh40k11e/` - source URL lists, the faction map, and reviewed decisions

## Verification

Use Node from `.nvmrc` (22.x) and Yarn Classic. Build before test, because the PWA tests read `dist/`.

```bash
yarn lint
yarn tsc --noEmit
yarn build
yarn test --run
```

After touching rules data, also run `yarn data:wh40k11e:rules` (fails on unresolved matched-play
timing) and `yarn data:wh40k11e:generate` (fails if the checked-in runtime is stale). Both need the
source candidates in `.cache/`; see CONTRIBUTING.md.

## Conventions

- Prettier: two spaces, no semicolons, single quotes, 110 columns. A pre-commit hook formats staged
  files.
- TypeScript is strict. The configured target forbids iterating a `Set`, `Map`, or `matchAll`
  directly (use `Array.from`) and the regex `u` flag.
- Sort generated output with code-unit comparison, never `localeCompare`.
- Interface work reuses the established components and visual language; see DESIGN.md.
